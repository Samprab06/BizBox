## Decisions

| Source principle | BizBox application |
| --- | --- |
| Age picker: clear hierarchy, direct tracking, momentum and detents | The active chapter is a clear state. Native scroll remains directly controlled; small glass selection feedback acknowledges an actual chapter selection. No unrelated picker is added. |
| Verification code: fewer words, stable geometry and state feedback | One headline and functional actions. Embedded product/tour loading retains its final frame geometry rather than moving the page. |
| Like button: immediate input response and contextual settling | Buttons compress on contact; the active chapter indicator moves as the same object. No fake business-success pulse or decorative counter. |
| Login: one purpose, contextual environment, concentric corners | Houston sunset imagery defines the world; foreground glass picks up its light. Product window radii account for frame padding. |
| AI chat: actual product, credible state and stable content | Use the actual application demo and public tour. A screenshot is only the original laptop display texture, never a stand-in for live content after entry. |
| Thank-you letter: overlapping phases and coherent materials | The product surface begins emerging from the physical display before the laptop handoff finishes. The camera, display rectangle, and DOM surface share the same origin. |
| Theme switcher: hairline, top highlight, genuine refraction and spatial continuity | Refractive treatment is localized at small glass rims; text stays undistorted. Sunset-tinted edges replace generic heavy shadows. |
| Password: meaningful feedback and awareness of state | Only useful controls and trustworthy states remain. The landing page does not add authentication, a character, or typing effects. |
| Animation set: ease-out entrances, origin-aware movement, local masks, brisk exits | Button feedback is short, headline reveals are local, repeated actions retarget, and the real MacBook display determines the camera entry. Ordinary UI does not bounce. |
| Polish set: actual product, optical centering, contrast and consistent geometry | The text, hardware, logo and product window are reviewed together at full size and on phone. Filler labels and redundant prose are removed. |
| Background/material set | Select one related family: sunset photography, anodized aluminum and charcoal liquid glass. The alternative textures are not layered indiscriminately into the page. |
| Design terms | Use optical rather than merely numerical balance, stable material construction, safe targets, interruptible motion, and progressive disclosure for interactive embeds. |

Sound was not added. Akshar requested snappy, satisfying animation; the current application of that request is tactile visual feedback. Passive scrolling, hover, and initial render do not produce sound. The mixed reference tracks are not an isolated sound library.

## Scope and limits

The reference gives a craft target, not exact shader, physics, or sound settings. The landing model is an original Blender approximation, not a manufacturer's hardware CAD model. Public Matterport attribution is retained. Its frames are not recorded/exported. App data and simulation meaning are unchanged. Idle rendering, rapid reversal, keyboard navigation and reduced motion are part of the verification, rather than optional aesthetic extras.
